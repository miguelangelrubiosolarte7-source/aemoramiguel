# X (formerly Twitter) & Aemora Cyber-Dark — Style Reference

## Tokens — Colors (Cyber-Dark Adaptation)
- `--color-x-blue`: `#1d9bf0` (Accents & Highlights)
- `--color-accent-ai`: `linear-gradient(135deg, #A855F7 0%, #EC4899 100%)` (Aemora AI)
- `--color-bg-root`: `#0B0F17` (Deep Void Black Canvas)
- `--color-surface-card`: `#161F30` (Surface Level)
- `--color-hairline`: `rgba(255, 255, 255, 0.08)` (1px Border dividers)
- `--color-text-primary`: `#F8FAFC` (Primary Text)
- `--color-text-secondary`: `#94A3B8` (Secondary / Handles / Timestamps)

## Tokens — Typography & Shapes
- **Font Family**: Inter, system-ui, -apple-system
- **Type Scale**:
  - Caption: 11px
  - Body: 15px (line-height: 1.33)
  - Subheading: 20px
  - Heading: 23px
- **Border Radius Rules**:
  - Buttons, Avatars, Tags, Pills: `9999px` (`rounded-full`)
  - Cards, Modals, Containers: `16px` (`rounded-2xl`)
  - Inputs: `4px` (`rounded-md`)
- **Layout Grid**:
  - Desktop Max Width: ~990px
  - 3-Column Grid: Left Nav (~68px-240px) | Center Feed (~600px) | Right Sidebar/AI Widget (~290px)
  - Card Gap: 0px (Separated exclusively by 1px hairline borders)
